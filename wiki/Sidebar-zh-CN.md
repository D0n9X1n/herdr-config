# 侧边栏

[English](Sidebar)

## 空间和 agent

每个空间显示一个两个字母的图块、名称、分支和一个状态标记。空间下面每个 agent 有一行，显示图标、标题和标记。工作中的 agent 显示旋转的弧线，被阻塞的显示菱形，已完成的显示对勾，空闲的不显示。空间显示它最紧急的 agent：先是阻塞，然后是完成，然后是工作中。

单击空间选中它；右键单击打开 Herdr 的空间菜单。单击 agent 聚焦它。

## 折叠

有 agent 的空间带一个箭头：展开时是 `⌄`，折叠时是 `›`。单击它可以隐藏或显示 agent。折叠状态会被记住。

## 收起

侧边栏一开始宽 256 px。收起按钮会保存当前宽度，并把侧边栏缩到 184 px。图块、名称、高亮和标记保留；分支行、agent 行、箭头和搜索隐藏。展开按钮恢复保存的宽度，没有时恢复为 256 px。宽度小于 220 px 就算收起。缩放永远不变。

## 宽度范围

侧边栏宽度保持在 184 到 480 px 之间。`layout.resize` 不理会布局的 `min` 和 `max`，所以 mod 会把超出范围的宽度改回一次。

## 搜索

搜索按钮在顶部打开一个过滤框。输入后只保留名称匹配的空间，不分大小写。按 Escape，或再点一次搜索按钮，会清空并关闭它。

## 注意

- `mods/apollo-spaces/lib.js` 里的 `SIZE_IS_ZOOMED` 认为侧边栏报告的宽度是设计像素。这只在缩放为 1 时验证过。在其他缩放下，收起和展开可能选错宽度。
- mod 之间不能共享文件，所以 `apollo-spaces`、`apollo-pane` 和 `apollo-status` 各自保存同一个 `branch.svg`。状态标记（`arc.svg`、`diamond.svg`、`check.svg`）也是这样复制的。修改时要一起改所有副本。
