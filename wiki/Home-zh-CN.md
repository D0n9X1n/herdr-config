# Apollo

[English](Home)

Apollo 是一个原创的 Herdr 布局，采用 MIT 许可。它使用 Apollo 配色，以及与 SonicTerm 一致的 macOS 和 Windows 快捷键。在 Windows 上它自己画窗口按钮。

## 页面

- [安装](Install-zh-CN)：把文件复制到你的 Herdr 主目录。
- [快捷键](Keys-zh-CN)：macOS 和 Windows 快捷键表，以及可以绑定的命令。
- [侧边栏](Sidebar-zh-CN)：空间、agent、收起和搜索。
- [面板](Panels-zh-CN)：Files、Changes、Specs 和 + 菜单。
- [Agent 上下文](Agent-Context-zh-CN)：告诉 agent 它运行在 Herdr 里。
- [开发](Development-zh-CN)：测试、实机安全、CI 和发布。
- [净室](Clean-Room-zh-CN)：Apollo 是怎样做出来的，用了哪些资料。
- [Herdr 笔记](Herdr-Notes-zh-CN)：Herdr 文档里没写的事实。
